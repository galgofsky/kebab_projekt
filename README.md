# 🌯 Projekt szkolny – Chilli Chill Kebab

Projekt responsywnej strony internetowej wykonany w HTML5 i CSS3 dla lokalnego biznesu  
---

## 📌 Opis projektu

Celem projektu było stworzenie nowoczesnej, responsywnej witryny internetowej dla lokalnej restauracji.  
Strona została wykonana bez użycia frameworków oraz JavaScriptu — wyłącznie przy użyciu:

- HTML5
- CSS3
- Flexbox
- CSS Grid

Projekt został przygotowany w ramach pracy zespołowej z wykorzystaniem systemu kontroli wersji Git oraz platformy GitHub.

## 🎨 Decyzje projektowe

### Dlaczego Flexbox?
Flexbox został użyty do stworzenia:
- menu nawigacyjnego,
- układu sekcji,
- wyrównywania elementów.

Pozwala on łatwo zarządzać układem jednowymiarowym.

### Dlaczego CSS Grid?
CSS Grid został wykorzystany w galerii zdjęć, ponieważ idealnie nadaje się do tworzenia układów dwuwymiarowych.

### Dlaczego zmienne CSS?
Zmienne CSS umożliwiają szybkie zarządzanie kolorami i zachowanie spójnego wyglądu całej strony.
